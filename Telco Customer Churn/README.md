# 📞 Telco Customer Churn Analytics

An end-to-end data analysis project (**Pandas, Seaborn, Matplotlib**) evaluating customer churn metrics, tenure distributions, contract type friction, and monthly charge impacts in the telecommunications sector.

## 🎯 Key Analytics & Business Questions
1. **Churn Rate Profiling:** Calculate baseline customer churn percentage across the organization.
2. **Contract & Tenure Friction:** Evaluate how short-term vs. long-term contracts affect attrition risk.
3. **Financial Impact:** Analyze monthly charges across churned vs. retained subscribers.

## 🛠️ Technical Stack & Workflow
- **Data Wrangling:** `pandas` (`groupby`, `value_counts` with normalization)
- **Visualization:** `seaborn` (`countplot`, `boxplot`), `matplotlib`
