# 📈 Stock Market Time-Series Analytics

A time-series analysis project (**Pandas, Seaborn, Matplotlib**) examining equity price volatility, moving averages (SMA 20/50), and daily returns.

## 🎯 Key Analytics
1. **Trend Identification:** Compute Simple Moving Averages (20-day & 50-day) to identify momentum shifts.
2. **Volatility Analysis:** Measure standard deviation of daily percentage returns.
